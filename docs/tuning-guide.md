# 调参指南

本指南基于数月的实板调试经验，记录了**必须遵守的操作顺序**与**踩过的坑**。

## 1. 上电与标定（每次必做）

### 1.1 正确开机序列

```
STOP → CLEAR → 下垂标定 → 校验 α ≈ ±180° → 写参数 → START
```

**关键点**：
- 板子落到 SAFE 后**必须主动发 CLEAR** 才能再 START（即使 `fault=0` 也一样）
- 标定前摆杆必须**完全静止下垂**（`|α̇| < 3°/s` 持续 2 s）
- 未标定时 α 读数约 ±80°，这是**正常现象**（不是故障）

### 1.2 标定校验

标定完成后，`offset` 应在 ±17 000~18 000 cdeg 附近，且显示 α ≈ ±180°。

**注意**：显示值 = `wrap(raw − offset) − trim`。因此挂垂显示为
`±(180 − trim/100)`。trim=245 时挂垂显示 177.6°，属正常。

## 2. trim 归零（每次重标定后必做）

**这是位置精度的头号杠杆。**

### 2.1 为什么 trim 会变

`trim` 补偿的是 α 传感器的零位偏置。每次重新做下垂标定，`offset` 都会变
（实测连续 5 次标定：−17 753 / −17 784 / +17 314 / −17 799 / −17 825 / −17 906），
因此**旧 trim 立即作废**。

作废后的后果：BAL 稳在 α=+9.9°，POS 入场必掉（te 偏差 ≈146°）。

### 2.2 自动归零流程

`tmp/night_trim.py` 的逻辑（可在 GUI 或脚本中复现）：

1. 起摆 → 进 BAL，测 12 s 的 `α_mean`
2. 若 `|α_mean| < 0.8°` 收敛，结束
3. 否则 `trim += α_mean × 100`（斜率 ≈0.01°/trim 单位，因 θe 吸收使其偏软）
4. 重复 2~4 轮

实测 2~3 轮收敛到 `|α| < 0.8°`。

### 2.3 手动三点扫描（备选）

```bash
python tmp/trim_sweep.py 150 250 350     # 每点保持 40 s，测 te 均值
```

线性插值取 te 过零点。历史实测：150→−23.4°、245→+3.7°、350→+26.6°（零点≈245）。

**斜率参考**：`te ≈ 0.15°/cdeg`（θe 吸收后）。理论值 `K1/K3 = 14.8°/°`。

## 3. K4 电量适配

K4（臂速阻尼）的有效增益正比于电池电压，**甜点随电量移动**：

| 电量 | 推荐 K4 | 实测 |
|---|---|---|
| 满电（v_probe ≈ 74°/s） | 9 500~14 000 | 满电扫描：9 500→\|te\|15.5°/pp56.6；11 000→11.6°/60.9；14 000→8.9°/42.5 |
| 80% | ~11 500 | 按比例外推 |
| 60%（v_probe ≈ 44.6°/s） | ~8 000 | 60% 实测甜点 |

**悬崖**：满电 K4=16 000 直接泵摆掉杆（α→111°）。留 20% 余量。

### 3.1 电量探针（GUI 参数页按钮）

`IO_TEST +800 duty × 0.9 s`，测臂速尾段均值 v，按线性内插估电量：

```
pct ≈ (v − 44.6) / (74.0 − 44.6) × 40 + 60
K4 ≈ 204·v − 1100        （截 [6500, 13000]）
```

**已知污染**：duty 800 落在软死区内，读数受臂位摩擦带影响很大
（实测同一电池 5.5~139.6°/s 乱跳）。**只作参考，不要盲信**。
更可靠的做法是直接观察 POS 保持时的 `|te|` 均值，偏大就调 K4。

## 4. 甩幅（起摆成功率）

`swing_amp` 控制甩摆力度。历史数据：

| 甩幅 | 效果 |
|---|---|
| 7 000 | 满电下稳妥（当前推荐） |
| 7 800 | 满电偏猛，捕获后瞬态掉摆率上升 |
| 8 800 | 可能进入全圈旋转（维持 2/3） |

**起摆成功率**（实测）：
- 历史最优批次：4/4 连成，连续稳摆 100.6 s
- 满电极端条件：7 次 4 成（失败集中在捕获后 1.3 s 内瞬态掉摆）

失败模式定位：捕获增强窗（800 ms）结束时若 POS K4 过高会撞"捕获增益悬崖"。
缓解：POS K4 降到 9 500。

## 5. 位置精度预期

**诚实的数字**（满电、trim 归零后）：

| 指标 | 数值 |
|---|---|
| `\|θe\|` 均值 | 8.9~12.3°（K4 六档扫描） |
| 峰峰 | 42.5~60.9° |
| 90 s 连续保持 | \|θe\| 13.5°、α 峰 13.8°、duty std 1 884 |
| 绝对目标执行精度 | Δ=0.0°（6/6 段隔离复测） |
| 静摩擦锁 | duty 恒零最长 2.81 s |

**误差构成**（重要）：
- **直流分量**：trim 残差 + 极限环整流 → 靠 trim 归零与位置摩擦补偿
- **交流分量（主体）**：0.25 Hz 自持极限环，峰峰 42~60°

极限环是**自持**的（Hilbert 包络阻尼 ζ≈0，14 段数据无一衰减），
能量由死区继电器与粘滑持续注入。单纯抬 K3/K4 无法消除——两者都已在稳定边界。

## 6. 故障排查

| 现象 | 原因 | 处置 |
|---|---|---|
| 连不上（BAD_SCHEMA） | 固件/上位机参数表不同版 | 检查 `DEBUG_SCHEMA` 与 `schema_id` 是否一致；注意 `sync_kernel.py` 会用固件树旧版覆盖上位机新版 |
| 连上但读不出数据 | 上位机 host 内核副本陈旧 | 同上 |
| 起摆多次失败 | 电池电量低 / 甩幅偏小 / 摆杆未静止 | 充电；甩幅调至 7 000；等摆杆静止 |
| BAL 活不过 1.3 s | 捕获增益悬崖（POS K4 过高） | 下调 POS K4 至 9 500 |
| POS 恒定偏差 90°+ | 标定错误（α 零位偏） | 重做标定 + trim 归零 |
| 位置误差 16~23° 直流 | 速度自适应 REF 设置过低 | 检查 `OUT_DZ_THDOT_REF` 应为 2 500 |
| 过零"咔咔"响 | 死区硬跳变 | 启用软死区（`DZ_SOFT_TH=1024`） |
| 齿轮箱高频抖动 | 换向无守卫 | 检查 `rev_guard` 120 ms 门限 |
| 运动中掉摆 | 移动期 K4 被软化 / 穿越高摩擦区 | K4 不软化；坏区阻尼器启用 |
| 串口周期性停顿数十秒 | CH340 在电机活跃期 USB 停顿 | 硬件问题；脚本侧用看门狗+断点续跑 |

## 7. 演示操作流程

### 7.1 定位演示（镜头3）

1. 连接 → 标定 → START 起摆 → 等 BAL 稳定
2. 输入 0~360° 绝对目标（最短路径自动计算，≤55° 分步）
3. 观察：目标斜坡 → 到位 → 静摩擦锁（duty 归零）

**GUI 保护**：帧校验自愈（固件 target 与航点偏差 >3° 时按当前臂位重锚）、
最小观察窗 1.2 s（防发步瞬间假完成）。

### 7.2 速度曲线演示（镜头5）

用目标斜坡当速度曲线：POS 内一步 MOVE，目标按 20°/s 匀速爬升，
臂跟随率实测 96%（目标 4.00°/s ↔ 臂均值 3.84°/s）。

**注意**：VEL_DEMO（定速旋转）在当前单输入 LQR 下不可达——
8 个版本全部失败，臂速通道在任何现有增益下都闭不上环。需要 2-DOF/MIMO 重设计。

## 8. 安全边界

- 电机点动 `IO_TEST` 限 ±2 000 duty
- POS 输出轨 ±9 500 duty
- `|α| > 15°` 拒绝进 POS
- 掉摆 / 超时 / 传感器坏帧 → SAFE，电机 coast
- 齿轮箱禁高频换向（120 ms 守卫）
